# 🤖 과제 2호: 멀티모달 자율주행 E2E — 멀티 에이전트 분할 설계

> 등재: 2026-10-23 (teacher 설계 원문 기록 · 구조화 및 소소 단위 결정은 학생 라벨) · 상태: 🟡 규격 고정 단계

## 0. 작업 원칙 (teacher 지정 — 최우선)

1. **인터페이스 규격(Tensor Shape) 먼저 정의** — 각 에이전트 개발 시작 전 입출력 텐서 형태를 고정(Interface Contract)하여 통합 시 충돌 최소화 → `00_INTERFACE_CONTRACT.md`
2. **모듈별 단위 테스트 병행** — 비전 단독 / 오디오 단독 / 리샘플러 압축률을 독립 스크립트로 검증 후 LLM 백본 결합 → `tests/`
3. **에이전트 병렬 분업** (2026-10-23 확정 방식) — 아래 A~D 4개 워크스트림을 agent 팀으로 병렬 수행

## 1. 에이전트 A: 👁️ 비전/공간 인코딩 전문가

**담당**
- MAE 또는 CLIP 비전 인코더 파이프라인 구축·최적화
- 고해상도(336×336) 프레임 분할, 패치 토큰 추출, 2D 공간 포지셔널 인코딩(RoPE 등) 주입
- 비디오 스트림 시공간(Spatio-Temporal) 토큰 캐싱 + Sliding Window 버퍼 관리

**목표**: 카메라 프레임에서 공간 디테일(나뭇잎/신호등)을 손실 없이 압축된 특징으로 변환

## 2. 에이전트 B: 👂 오디오/청각 인코딩 전문가

**담당**
- WavLM 또는 AST 기반 오디오 인코더 파이프라인 구축
- 파형 → Log-Mel Spectrogram 변환, 시간축(Temporal) 프레임 특징 추출
- 비디오 프레임레이트 ↔ 오디오 윈도우 비동기 타임스탬프 싱크로나이제이션(Rate Mismatch 해결)

**목표**: 경적·타이어 마찰음·주변 소음의 청각 단서를 정확한 타임스탬프로 시각 토큰과 정렬

## 3. 에이전트 C: 🔗 멀티모달 융합·리샘플러 아키텍트

**담당**
- 비전+오디오 토큰 → **고정 32개 잠재 벡터**로 압축하는 Perceiver Resampler 구현 (O(N²) 병목 차단)
- 모달리티별 Cross-Attention 레이어 + Token Type Embedding 결합
- 압축 토큰의 Qwen-LLM 입력 시퀀스 인터리빙(Interleaving)

**목표**: 이질적 두 감각을 LLM이 소화 가능한 일관된 단일 시퀀스로 융합

## 4. 에이전트 D: 🚗 정책 추론·액션 제어 엔지니어

**담당**
- Qwen-LLM 백본 로드 + 멀티모달 프롬프트 컨텍스트 구성
- 연속 제어값(스티어링·스로틀/브레이크) → **256 bin → 전용 토큰 ID 매핑** (Action Tokenization & Detokenization)
- 출력 토큰 역산 → 물리 제어 신호 + **EMA 저역통과 필터** (급격한 떨림 방지)

**목표**: 멀티모달 문맥 이해 + 부드러운 주행 액션 토큰 실시간(<50ms) 출력 루프 완성

## 5. 근거 계승 (assignment 1호에서 이월 — RT-2 2307.15818 §3.2 검증 기준)

| 항목 | 계승 근거 |
|---|---|
| 256 bin 균등 이산화 | RT-2 §3.2 (직접 조회 2026-10-23) |
| bin 중점 복원 default | 데모 D 자체 관측: floor 복원의 부호 편향이 계-드리프트 생성; 중점 복원 K=256에서 RMS 20배 개선 (라벨 a: RT-2 본문 복원식 미기술 — 본 프로젝트 규약 선택) |
| EMA α=0.3 기본 | 데모 C: α=0.1은 lag 적분으로 경로 오차 ×8.3 — 폐 루프 피드백 전제 하 가볍게 |
| LLM 출력 vocab 제약 | RT-2 §3.2 Output Constraint — 유효 액션 토큰만 sampling |

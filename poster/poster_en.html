1. Background & Interface Contract v1.0

Why Existing VLM Driving Falls Short

  • No acoustic awareness: image-text-centric VLMs cannot perceive horns, tire screech, or ambient noise during driving.
  • O(N2) attention blowup: naive token growth across modalities makes fusion cost explode with scene length.
  • Real-time unmet: closed-loop control requires action output <50 ms; raw VLM pipelines exceed it.

2. Modality Fusion & Compression (Agent C)

Perceiver Resampler: cross-attention fuses C_IN: (T·576 + 250, 1024) + 0/1 modality-type tokens into C_OUT: (32, 896) — ALWAYS this shape, regardless of input length (27 tokens or 33,632 tokens: same output).

The Reform: O(N2) Blocked by Contract, Not by Hope

The fixed (32,896) resampler output is a structural proof, tests enforce it: attention cost of the fusion boundary is input-length-independent. The pipeline's stability is guaranteed by an interface contract, verified by a mock-proven test suite (7/7 PASS) — real implementations must pass the same tests.

Action tokenizer: continuous steering ∙ throttle → 2 output tokens "st thr" → 256-bin midpoint restore (≤ bin-width/2 error; beats RT-2 floor restore per our demo D) → EMA α = 0.3 low-pass (jitter ≤ 0.3× input; α=0.1 path-error ×8.3 in closed loop)

3. Methods, Verification & Roadmap

Key Methodologies

  • Perceiver bottleneck: cross-attention keeps global context while discarding micro-noise — a fixed latent horizon (32) instead of unbounded token growth.
  • Behavioral cloning via 256-bin discretization: continuous control becomes a language-model-friendly token prediction problem (RT-2 §3.2 legacy).
  • Metric restoration discipline: bin-midpoint default (floor-restore sign bias → cumulative drift, RMS ×20 penalty observed at K=256) + EMA α=0.3 (carried over from demo evidence, RT-2 §3.2).

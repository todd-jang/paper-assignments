## 1. 팩트시트 — RT-2 (2307.15818, ar5iv 본문 2026-10-23 세션 직접 조회)

### 연속 액션 → 토큰 변환 (§3.2, RT-1 프로토콜 이식 — 본문 [Brohan 2022] 명시)

| 항목 | 본문 근거 |
|---|---|
| 액션 공간 | 6-DoF 위치/회전 변위 + 그리퍼 확장 + 종료 명령 1개(이산) |
| 이산화 | 연속 차원 **균등 256 bin** → 액션 = **8개 정수** |
| 토큰 매핑 A | PaLI-X: 0~1000 정수에 고유 토큰 → **기존 정수 토큰 재활용** |
| 토큰 매핑 B | PaLM-E: **사용 빈도 최하위 256 토큰을 덮어써서** 액션 어휘 치환 (symbol tuning, 본문 인용) → 신규 파라미터 0 |
| 서식 | "terminate Δposx Δposy Δposz Δrotx Δroty Δrotz gripper_extension" — 예: "1 128 91 241 5 101 127" |
| 출력 강제 | 액션 과제 시 **유효 토큰만 sampling하는 vocab 제약** (Output Constraint); 언어 과제는 풀 vocab |
| 공동 미세조정 | 로봇 데이터 + 웹 데이터 배치 내 비율 균형(Co-Fine-Tuning) |

### 실시간 한계 (§3.3 — 본문 스스로 인정)

- 55B(PaLI-X): **1–3 Hz** (멀티 TPU 클라우드 경유) / 5B: **~5 Hz** — "수십 ms 제어 주기"와 구조적 비호환
- Language-Table 실험: PaLI-3B, 액션을 텍스트 "X Y" (−10…+10)로 직렬화, ~5 Hz (Table 3 실험, 성적 90±10 §4.1)

### 선대(대조군) 월드모델 — V-JEPA 2 (2506.09985 abs 직접 조회)

- 사전학습: 100만 시간+ 인터넷 영상, **action-free JEPA** (잠재 예측, 픽셀 재구성 없음)
- 이해: SSv2 77.3 top-1, Epic-Kitchens-100 액션 예츠 39.7 recall@5 (task-specific 모델超)
- 8B LLM 정렬: PerceptionTest 84.0, TempCompass 76.9
- **V-JEPA 2-AC**: Droid 비라벨 로봇 영상 **62시간 미만** 포스트트레이닝 → 타 랩 2곳 Franka **제로샷** 이미지-골 픽앤플레이스 계획 (배치 환경 데이터 0, 과보 0)

## 2. 합성 실습 기록 (2026-10-23, 총 3 데모 — 자체 생성 시나리오, 원문 수치 비교 없음)

### 데모 A: K 스윕 + 이론 검산 (조향±1 / 스로틀 0-1)

- RT-2식 균등 bin(floor → `idx/(K−1)` 복원): **MSE ≈ W²/3(K−1)²** 정합 — 조향 K=16/64/256: 4.38e-3 / 3.24e-4 / 2.17e-5 (이론 5.93e-3 / 3.36e-4 / 2.05e-5), max 오차 = bin폭 W/(K−1) 상한 정확 타격
- 스로틀 채널도 동일 정합: 1.45e-3 / 6.98e-5 / 5.13e-6
- 직렬화 검증: t=7.8s 조향+0.760 → PaLI-X식 "224 177" · Lang-Table식 "+8 +7" (범위 내)

### 데모 B: 캘리브레이션 이상값 함정 (조향 clean + 이상값 1개 = +3.0)

- 고정 범위 [-1,1]: 2.17e-5 (기준) · naive min/max: **4.95e-5 = 2.3배 악화, 유효 분해능 1/4** · 백분위 클립 [0.5,99.5]: 4.03e-6 복구
- [서비스로 힌트] v1 시나리오 버그(신호 max 1.46 > 선언 ±1) 재현 결과: **범위 선언 오류 시 클리핑 포화 → K 무관 에러 플로어 4.7e-2** — "K를 키워도 캘리브레이션이 틀리면 끝" — 함정 ②의 상위 판정

### 데모 C: EMA 스무딩 트레이드오프 + open-loop 관측 (toy 식물 y'=5·steer, dt=0.1s)

| 항목 | 지터(mean\|step\|) | 경로 RMS | 결론 |
|---|---|---|---|
| curve K=256 off | 0.0155 | 0.218 | raw 0.0134 대비 양자화 지터 소 (+) |
| curve K=256 EMA 0.3 | 0.0095 | 0.596 (×2.7) | 지터 반감 vs lag 비용 |
| curve K=256 EMA 0.1 | 0.0081 | 1.813 (×8.3) | 과소 스무딩 → lag 적분 |
| step K=256 off→0.1 | 0.60 max→0.06 | 0.237→2.181 (×9.2) | 스텝 명령엔 스무딩이 lag 독 |

**제안**: α ≥ 0.3 수준 가볍게, closed-loop 피드백 존신 전제로 탈취단 스무딩은 최소화

### 데모 D: floor 복원 편향 발견 (실험 중 자체 발견)

- RT-2식 `idx/(K−1)` floor 복원은 **부호 편향 일관**(rec ≤ x, 관측 mean(qerr) +3.77e-3 @K=256) → open-loop 적분 시 **계-드리프트** (curve final −0.377 @K=256)
- **bin 중점 복원으로 제거**: K=256 drift −0.377→**+0.015**, RMS 0.218→**0.011 (20배)** / K=64: −1.535→+0.052 / K=16: −4.589→+2.078 (잔여, 아래 라벨 b)

### 라벨 (정직 선언 — 중요)

- [라벨 a] RT-2 본문은 **복원식(dequantization) 세부를 기술하지 않음** — "RT-2식 idx/(K−1)"은 *본 실험의 규약 선택*이며, floor 편향·중점 복원 개선은 **본 시나리오의 자체 관측**으로 RT-2의 결함 증명이 아님
- [라벨 b] K=16 잔여 편향(+2.08)은 (K−1) 간격 규약 비대칭(top bin 오버슈트)이 원인이라는 추정 — canonical K bins × W/K 중점식이면 더 해소될 것 — **시트 밖 추론, 미검증**
- [라벨 c] 데모 C/D 간이 식물은 **open-loop 적분**이라 lag·편향을 과대평가 — 실제 closed-loop에서는 피드백이 드리프트 일부 자체 복구

### 데모 중 자체 발견 버그 2건 (측정 강규 "모든 수치는 검산" 수확)

1. v1 시나리오: 조향 합성 진폭 설계 착오(개별 tanh 합 1.46 > 선언 ±1) → 검산시 즉시 발견 → 범위 보정 재실행
2. 복원 오차 출력식 누락(스케일·오프셋 누락, err 0.88 불가능 조합) → 검산시 발견 → 실제 복원 오차 3.3e-3 ≤ 상한 0.0078 정합

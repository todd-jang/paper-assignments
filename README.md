# paper-assignments

SLOW PAPER 논문 일기(`paper-diary`) 밖의 **확장 과제 전용 레포** — 교차 종합 설계·실습 과제를 논문 하루 퀘스트와 분리해 관리.

## 하위 과제

| 디렉토리 | 과제 | 상태 |
|---|---|---|
| `e2e-multimodal-rt/` | E2E 멀티모달 실시간 에이전트 (시각+청각+액션, RT-2/V-JEPA 2 근거) | 🟡 팩트시트+실습 기록 완료, 퀘스트 11/04 예정 |

## 규약 (paper-diary와 동일 계승)

- **작업 방식 (2026-10-23 teacher 확정): 다중 에이전트 병렬 분업** — 퀘스트·실습·원문 검증을 agent 팀으로 병렬 수행 (역할 분업은 과제별 세부 섹션에 기록)

- 모든 수치는 논문 고유 표/절/라벨 + 조건 첨부 (split · 해상도 · 크기 조건)
- 합성 실습 수치 ↔ 논문 수치 직접 비교 금지
- 시트 밖 추론(推論)은 정직 라벨로 명시
- 커밋은 명시적 승인 후, 한국어 PLAIN 커밋 메시지
